# ReliefCheck UI 디자인 적용 메모

## 적용 기준

`/Users/do_not_delay/Downloads/DESIGN (1).md`는 Apple 웹/HIG 레퍼런스 기반 디자인 토큰 문서다. ReliefCheck는 공공 재난구호 현장 단말이므로 해당 문서를 제품 사실이나 네이티브 플랫폼 규칙으로 그대로 복제하지 않고, 키오스크 화면에 적합한 범위만 적용한다.

## 반영한 요소

| 항목 | 적용 |
|---|---|
| 배경 | `#f5f5f7` 포그 캔버스 |
| 기본 표면 | 흰색 패널 |
| 본문 텍스트 | `#1d1d1f` 중심 |
| 보조 텍스트 | `#6e6e73` |
| 주요 액션 | `#0071e3` |
| 보조/외곽 액션 | `#0066cc` |
| 버튼 형태 | 36~44px 높이의 pill 형태 |
| 타이포그래피 | SF Pro 계열 우선, 한국어 fallback 포함 |

## 의도적으로 조정한 요소

- 카드 반경은 18px HIG 문서 카드 값을 쓰지 않고 8px로 유지했다. 제공 문서에서도 HIG 웹사이트 카드 값을 범용 플랫폼 토큰으로 보지 말라고 명시되어 있고, ReliefCheck는 작업형 키오스크이기 때문이다.
- 음영은 거의 제거했다. 깊이는 그림자보다 선, 상태색, 레이아웃 위계로 만든다.
- 레퍼런스의 음수 자간 값은 적용하지 않았다. 키오스크의 한글/영문 혼합 상태 문자열이 안정적으로 보여야 하므로 `letter-spacing: 0`을 유지한다.
- 모든 버튼을 마케팅 CTA처럼 만들지 않고, 스캔 후보·위험 테스트·관리 액션의 색상 역할을 분리했다.

## 검증 결과

- 데스크톱 1440px 화면에서 3개 패널 정상 렌더링
- 모바일 390px 화면에서 텍스트 겹침 없음
- 출력 파일 절대경로가 UI에 노출되지 않음
- 기존 정책/거래 단위 테스트 7개 통과
