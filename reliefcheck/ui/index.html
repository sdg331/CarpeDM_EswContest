결선 시연 흐름

  1. 활성 가구 카드와 물품 태그를 정상 순서로 인식한다.
  2. 정책 체크리스트가 모두 통과되고 지급확인증을 출력한다.
  3. 같은 물품 또는 한도 초과 지급을 재시도해 중복 차단을 보여준다.
  4. 카메라 불일치와 프린터 실패를 분리 처리한다.
  5. 운영 대시보드에서 재고, 거래, 장치 상태를 확인한다.
